Додай свої дієслова

Імпортуй CSV або JSON з перекладом і шістьма формами. Нові дієслова одразу потраплять у гру.

Формат файлу та зразки

Завантаж зразок і заміни слова своїми. Для кожного дієслова потрібні: infinitive, translation, ich, du, er, wir, ihr, sie. Поле er означає er/sie/es, а sie — sie/Sie. Вписуй лише форму без займенника; для відокремлюваних дієслів — обидві частини, наприклад stehe auf.

CSV: UTF-8, роздільник — кома або крапка з комою. JSON: список об’єктів. Необов’язкові поля: group (regular або special) та rule (твоя підказка). Без group слово буде лише в загальній та імпортованій добірках. До 1000 дієслів загалом, файл до 1 МБ. Повтори пропускаються, наявні слова не змінюються. Якщо є помилка формату, весь файл лишається неімпортованим.

Слова зберігаються лише у цьому браузері. Щоб перенести їх на телефон, натисни «Зберегти мої слова» та імпортуй отриманий JSON на телефоні.

📖 Підказник: усі дієслова та правила

Тренуємо форми з фото, переважно теперішній час (Präsens). möchten — ввічлива форма «хотілося б» (Konjunktiv II від mögen). beginnen — сильне дієслово, але у Präsens відмінюється без зміни голосної. heißen має du heißt без додаткового -s.
